# `opencv-python`. It is a hard dependency of the WORKERS — capture, clip recording,

# because `qorgan.web` reached `media_root` through `qorgan.notify` → `events.recorder`,

# container failure mode nobody would enjoy debugging at a demo.
#

# blocked-import test measures, but they are needed to RUN it — alembic for the migration
# on boot, psutil for the worker diagnostics the dashboard renders.
