# Начальные данные стенда

Эта папка **пуста в репозитории** и заполняется вручную — тем, кто разворачивает стенд.
Положенное сюда попадает в образ и раскладывается на том **при первом запуске**.

## Что сюда класть

| Файл | Что это |
|---|---|
| `qorgan.sqlite3` | База: уроки, места, счётчики, подписи планов рассадки, учётные записи |
| `media/classvision/<разбор>/*.jpg` | Кадры записей, поверх которых панель рисует рамки мест |

## Как подготовить

База копируется **не `cp`**, а через собственный механизм SQLite: рядом с файлом живёт
журнал упреждающей записи, и обычное копирование увезёт базу без последних изменений.

```bash
cd qorgan-ai-main
python - <<'PY'
import sqlite3
src = sqlite3.connect("file:data/qorgan.sqlite3?mode=ro", uri=True)
dst = sqlite3.connect("seed/qorgan.sqlite3")
src.backup(dst); dst.execute("VACUUM"); dst.close(); src.close()
PY
mkdir -p seed/media && cp -R media/classvision seed/media/
```

Затем — обычный `git add`, коммит и `railway up`.

## Правила, которые механизм соблюдает

* **Существующая база никогда не перезаписывается.** Иначе одно развёртывание стёрло бы
  всё, что школа успела внести. Заполнение происходит только тогда, когда на томе базы нет.
* **Кадры докладываются, а не заменяются**: файл, который уже есть на томе, не трогается.
* Выключается переменной `SEED_ON_FIRST_BOOT=0`.

## Осторожно: здесь персональные данные

База несёт настоящие имена учеников, а кадры — записи реальных уроков. Репозиторий с
заполненной папкой `seed/` **обязан быть закрытым**, и разворачивать его следует только там,
где школа согласна хранить эти данные.

Если стенд нужен без персональных данных, положите базу, содержащую только синтетический
класс: он даёт и классы, и недельную динамику, и подписанные места — с вымышленными
фамилиями и без единого настоящего ребёнка.
